# FotoGest Pro

Aplicación web para gestionar servicios, sesiones, pagos y galerías privadas de un negocio de fotografía.

## Objetivo del proyecto

FotoGest Pro pretende facilitar la gestión diaria de un pequeño negocio de fotografía, centralizando la información de los servicios, las solicitudes de sesiones, los pagos y las galerías privadas de cada cliente.

La aplicación complementará la web profesional de fotografía existente, sin sustituirla.

## Tecnologías previstas

- **Base de datos:** MySQL
- **Backend:** Laravel con PHP, mediante una API REST
- **Frontend:** Vue.js
- **Alojamiento:** Railway

Estas tecnologías son la propuesta inicial del anteproyecto y podrán concretarse durante el desarrollo.

## Funcionalidades previstas

- Consulta pública del catálogo de servicios.
- Registro e inicio de sesión.
- Gestión de servicios y tarifas.
- Solicitud y seguimiento de sesiones fotográficas.
- Registro y consulta de pagos.
- Acceso privado a las galerías fotográficas de cada cliente.
