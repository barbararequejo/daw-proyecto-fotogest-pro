# FotoGest Pro · Backend (API REST)

API REST de FotoGest Pro desarrollada con Laravel y MySQL. La documentación completa está en el [README principal](../README.md) y en la carpeta [`docs/`](../docs).

Comandos principales:

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan jwt:secret
composer db:reset
php artisan serve
```
